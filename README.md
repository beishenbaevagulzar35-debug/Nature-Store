# Nature Store

Адаптивный магазин косметики на React, Vite, Express и SQLite. Работает на Node.js 24+ (для встроенного SQLite).

## Запуск

```bash
npm install
npm run dev
```

При первом локальном запуске сервер создаст `.env`, SQLite-базу `server/data/nature-store.sqlite`, заполнит каталог имеющимися товарами и сгенерирует случайный пароль администратора. Логин и пароль появятся в терминале; пароль также хранится локально в `.env`. Не публикуйте этот файл.

- Сайт: `http://localhost:5173`
- Админ-панель: `http://localhost:5173/admin`

Порт сервера и данные администратора можно задать в `.env`. В production обязательно установите собственный `JWT_SECRET` длиной не менее 32 символов, `ADMIN_USERNAME` и пароль администратора длиной не менее 12 символов, включите HTTPS и используйте постоянное защищённое хранилище для `server/data` и `server/uploads`.

## Возможности

- Каталог с категориями, фильтрами, поиском, сортировкой и страницами товаров.
- Корзина с серверной проверкой цены, наличия и количества при оформлении.
- SQLite хранит товары, заказы, заявки на консультацию, отзывы и настройки магазина.
- Админ-панель управляет товарами, изображениями, новинками, бестселлерами, скидками, заказами, статусами, заявками, отзывами и баннером.
- Фотографии товаров и разделов берутся из локальных файлов `public/products`; загрузки администратора хранятся в `server/uploads`.
- Публичный отзыв поступает в админ-панель и публикуется только после одобрения.
- Заказы доступны в админ-панели. Для автоматических уведомлений в Telegram/email или онлайн-оплаты нужно подключить и настроить соответствующего провайдера.

Перед публикацией в интернете настройте HTTPS и резервное копирование базы, а также проверьте условия доставки, оплаты и обработки персональных данных.
